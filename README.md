Greek Budget Management System (2025)

Η παρούσα εργασία αφορά την ανάπτυξη ενός συστήματος προσομοίωσης και ανάλυσης του κρατικού προϋπολογισμού της Ελλάδας για το έτος 2025. Το έργο υλοποιείται στο πλαίσιο ομαδικής εργασίας του μαθήματος και αναπτύσσεται από την ομάδα DETARIES. Η εφαρμογή είναι γραμμένη σε Java και ακολουθεί δομημένη και επεκτάσιμη αρχιτεκτονική.
Οδηγίες μεταγλώττισης προγράμματος
Το έργο χρησιμοποιεί το εργαλείο Maven για τη μεταγλώττιση και τη διαχείριση των εξαρτήσεων. Για τη μεταγλώττιση του προγράμματος απαιτείται εγκατεστημένο το Maven και Java JDK. Η μεταγλώττιση γίνεται με την εντολή mvn clean package από τον ριζικό φάκελο του έργου.

Οδηγίες εκτέλεσης προγράμματος
Η εκτέλεση της εφαρμογής γίνεται μέσω Maven με την εντολή mvn exec:java. Εναλλακτικά, αν έχει παραχθεί εκτελέσιμο αρχείο JAR, η εφαρμογή μπορεί να εκτελεστεί με την εντολή java -jar target/greek-budget-app-1.0-SNAPSHOT.jar.
Οδηγίες χρήσης προγράμματος
Με την εκκίνηση της εφαρμογής, ο χρήστης βλέπει το κεντρικό μενού επιλογών. Μέσα από αυτό μπορεί να επιλέξει την επεξεργασία του προϋπολογισμού σε περιβάλλον sandbox, την προβολή του πραγματικού προϋπολογισμού, την εμφάνιση στατιστικών στοιχείων ή την έξοδο από το πρόγραμμα. Στο περιβάλλον επεξεργασίας, ο χρήστης μπορεί να τροποποιήσει έσοδα και έξοδα χωρίς να επηρεάζονται τα αρχικά δεδομένα, καθώς και να επαναφέρει τις αλλαγές στις αρχικές τιμές μέσω της λειτουργίας reset. Όλες οι τροποποιήσεις ελέγχονται ώστε να μην επιτρέπονται αρνητικά ποσά.

Δομή αποθετηρίου
Το αποθετήριο περιλαμβάνει τον φάκελο src/main/java όπου βρίσκεται ο πηγαίος κώδικας της εφαρμογής στο πακέτο gr.budget. Εκεί περιλαμβάνονται οι κλάσεις App, Expense, Revenue, BudgetEditor, Statistics και Comparator. Στον φάκελο src/main/resources βρίσκονται τα αρχεία expenses.json και revenues.json, τα οποία περιέχουν τα αρχικά δεδομένα του προϋπολογισμού.

Διάγραμμα UML και σχεδιασμός κώδικα
Η εφαρμογή ακολουθεί αντικειμενοστραφή σχεδίαση. Η κλάση App αποτελεί το σημείο εκκίνησης και διαχειρίζεται τη ροή του προγράμματος. Οι κλάσεις Expense και Revenue αναπαριστούν τα έξοδα και τα έσοδα αντίστοιχα. Η κλάση BudgetEditor παρέχει λειτουργίες επεξεργασίας του προϋπολογισμού σε sandbox περιβάλλον. Η κλάση Statistics υπολογίζει και εμφανίζει ποσοστιαία στοιχεία για τα έσοδα και τα έξοδα. Η κλάση Comparator χρησιμοποιείται για τη σύγκριση διαφορετικών καταστάσεων προϋπολογισμού. Το UML διάγραμμα αποτυπώνει τις σχέσεις μεταξύ των παραπάνω κλάσεων.

Δομές δεδομένων και αλγόριθμοι
Η εφαρμογή χρησιμοποιεί λίστες τύπου List για την αποθήκευση των εξόδων και των εσόδων. Τα δεδομένα φορτώνονται από αρχεία JSON με τη χρήση της βιβλιοθήκης Jackson. Για την υλοποίηση του sandbox περιβάλλοντος χρησιμοποιείται deep copy των αρχικών δεδομένων. Οι αλγόριθμοι περιλαμβάνουν υπολογισμό αθροισμάτων, ποσοστιαίων τιμών, έλεγχο εγκυρότητας εισόδου και σύγκριση διαφορετικών σεναρίων προϋπολογισμού.

Τεχνική τεκμηρίωση και μετρικές
Στην παρούσα φάση, το έργο περιλαμβάνει έξι κλάσεις, περίπου είκοσι δύο μεθόδους και πάνω από εξακόσιες γραμμές κώδικα. Η ανάπτυξη γίνεται με τη χρήση Git και GitHub, με διαχωρισμό λειτουργιών σε branches και έλεγχο κώδικα μέσω pull requests. Προβλέπεται περαιτέρω τεκμηρίωση με JavaDoc καθώς και επέκταση των ελέγχων με JUnit tests και μετρικές κάλυψης κώδικα.

Ομάδα
Το έργο αναπτύσσεται από την ομάδα DETARIES στο πλαίσιο της ομαδικής εργασίας του μαθήματος.
